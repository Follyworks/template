# Support

## Where

- Bug reports and feature requests: [Issues](../../issues), use the templates.
- Questions, ideas, "is this possible", "how do I": [Discussions](../../discussions).
- Not here: DMs, comments on store pages. They get missed, then they get ignored, and
  that's on nobody.

## What gets fixed

The support matrix is in [docs/support-matrix.md](docs/support-matrix.md). The short form:

- One Minecraft version at a time gets everything.
- The previous version gets crash and save-corruption fixes, nothing else.
- Anything older gets nothing. Not out of spite, a backport is weeks of work per version
  and this is a hobby.

## A bug report that gets fixed fast

1. The full version string off the jar, `1.2.0+1.21.1`, with the `+` part.
2. NeoForge version.
3. `latest.log`, or the crash report. Drag the file in, don't paste 4000 lines.
4. Steps. "It crashed" is a feeling, "placed X next to Y, right-clicked Y" is a repro.
5. Whether it happens with ONLY this mod installed. Half of all reports are another mod.

Miss one of those and the first reply is going to be asking for it, which costs both of us
a day.

## Response time

Days, sometimes a week. Crashes and save corruption jump the queue.
